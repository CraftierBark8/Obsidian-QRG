# Obsidian-QRG
[![cc-by-sa.png](README%20Files/cc-by-sa.png)](LICENSE) <a href="https://obsidian.md"> <img src="README%20Files/obsidian-logo-gradient.svg" height="67" alt="The Obsidian notes app logo" link="https://obsidian.md/"/> </a>

A quick reference guide for the markdown flavour used in the [Obsidian notes app](https://obsidian.md/) that you can drag and drop directly into your Obsidian vault for quick and easy referencing.
> [!NOTE] 
> This project is not affiliated with nor endorsed by Obsidian.
***
## 💻 Usage
> [!NOTE] 
> Some Obsidian settings and extensions change how markdown is rendered and typed out. This guide is based off of a stock Obsidian install. Formatting on your install may be different depending on your settings & extensions.

Get the latest Obsidian Quick Reference.md file from the [releases](https://github.com/CraftierBark8/Obsidian-QRG/releases) page. \
Copy and paste into your Obsidian vault and that's it!

***
## ℹ️ Markdown Info Included
Topics currently covered in the quick reference guide:
- Text Formatting Basics (bold, italics, strikethrough, etc)
- Headings
- Lists
- Horizontal Lines
- Task Lists & Checkboxes
- Tags
- Links
    - URL Links
    - External Image Links
    - Internal (within Obsidian vault) note links
    - Internal Images and Other Files
- Embeds & Attachments
- Tables
- Callouts
- Code Blocks
- Footnotes
- Comments
